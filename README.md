# Not Now Dear… I'm Gathering My Thoughts

Official website for the novel **Not Now Dear… I'm Gathering My Thoughts** by
Tristan Coates.

Built with [Astro](https://astro.build) · deployed on [Vercel](https://vercel.com)
from GitHub · no database required.

## Quick start

```bash
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # production build into /dist
```

## What's inside

- Single, cinematic landing page (hero, story, gallery, about, reader reactions,
  worldwide retailers, journal feed, newsletter).
- Markdown‑powered blog with auto‑generated article pages, categories, tags,
  reading time, share buttons and moderated comments (Giscus).
- Full SEO: meta tags, Open Graph/Twitter cards, JSON‑LD (Website, Book, Person,
  Article), sitemap, robots.txt and an RSS feed.
- GDPR newsletter (Buttondown, double opt‑in) with an auto‑synced
  `subscribers.csv`.
- Privacy‑friendly, consent‑gated analytics and a cookie banner.

## Editing the site

See **[DOCUMENTATION.md](./DOCUMENTATION.md)** for a plain‑English guide to adding
blog posts, updating retailer links, managing subscribers, and configuring the
newsletter, comments and analytics.

Most day‑to‑day settings live in `src/consts.ts`.
